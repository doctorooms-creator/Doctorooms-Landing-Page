   385→   * FOUC safety net for the hero entrance choreography.
   386→   *
   387→   * The hero uses GSAP `.from()` tweens which set opacity:0 + y-offset as
   388→   * the *starting* state and animate back to the natural state. With
   389→   * useLayoutEffect, GSAP applies that start state before the browser
   390→   * paints, so the user should never see the SSR markup flash visibly.
   391→   *
   392→   * However, in the gap between SSR HTML arriving and React hydrating,
   393→   * the server-rendered markup is visible. This rule pre-hides the hero
   394→   * choreography targets whenever JS is enabled (html.js is set by the
   395→   * inline script in <head>) so the SSR markup cannot flash. If JS is
   396→   * disabled or fails to load, html.js is never added and the content
   397→   * stays visible (good for SEO / no-JS accessibility).
   398→   *
   399→   * GSAP overrides these inline as soon as its `from()` tween runs.
   400→   */
   401→  html.js [data-hero-step],
